# Data Preprocessing Using Pandas

## Objective

This project demonstrates preprocessing of an employee dataset using Python and Google Colab.

## Tasks Performed

- Loaded dataset
- Explored dataset
- Checked missing values
- Removed duplicates
- Detected outliers
- Removed outliers
- Label Encoding
- One-Hot Encoding
- Min-Max Scaling
- Standardization
- Correlation Analysis
- Heatmap
- Feature Engineering
- Data Cleaning
- Train-Test Split
- SMOTE Balancing
- Data Visualization
- Saved cleaned dataset

## Tools Used

- Google Colab
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
